# WIN · fireworks-finale

- **verdict:** WIN ("bravo on fireworks")
- **surface:** FireworksFinale + EndCard
- **human's words:** "bravo on fireworks by the way" · "that is really good"
- **date / version:** v8 (assembled) → v11 (current)

## What worked
The user's explicit brief — "def fireworks… leave the MyGov logo in a haze of smoke that is revealed for the end" — delivered as: transition to the accurate spider-map diagram → seeded **deterministic** particle bursts (burst/willow/ring, no `Math.random`) erupting over it → smoke haze building → the MyGov logo (crown + wordmark) revealed within the smoke → hold → fade to black → clean end card (logo + scannable QR + URL). All frame-based, all reproducible.

## Why it's context, not a target
A pure creative flourish the user loved — but a **one-off**, and the file audit flags it as the project's heaviest render load (~1,600 blurred circles + 14 blur blobs on the same frames). It is NOT a template every video should imitate (chapter cards are the reusable harvest; see strategy §9 Phase C). Recorded as a win so the judge knows this *cleared the gate*, and as a caution that novelty like this is exactly what a winner-picking judge would have wrongly rejected — the reason Lock 2 detects fails, not winners.
